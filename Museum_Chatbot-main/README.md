# Museum Chatbot – Interactive Ticket Booking & Virtual Experience

An engaging museum chatbot web application built with HTML, CSS, and JavaScript for the frontend, and MongoDB for backend data storage.  
It allows visitors to explore upcoming events, book tickets, experience a virtual tour, and enjoy an interactive quiz — all in one platform.

--------------------------------------------------
FEATURES
--------------------------------------------------
1. Virtual Tour  
   - Explore the museum’s highlights online.

2. Quiz  
   - Test your knowledge of museum exhibits and history.

3. Event Ticket Booking  
   - Chatbot shows upcoming events with assigned event numbers.  
   - User selects an event number and enters the number of tickets.  

4. Payment Gateway (Dummy)  
   - Simulates payment for ticket booking.

5. Booking Confirmation  
   - Displays confirmation page after payment.

6. Event Details  
   - Shows date, time, and availability for each event.

7. MongoDB Data Storage  
   - Stores bookings including event name, ticket count, user details, and booking date/time.

--------------------------------------------------
TECH STACK
--------------------------------------------------
- Frontend: HTML, CSS, JavaScript
- Backend: MongoDB (for booking data storage)

--------------------------------------------------
HOW IT WORKS
--------------------------------------------------
1. User greets the chatbot or views the events list.
2. Selects an event number from the list.
3. Enters the number of tickets required.
4. Redirected to the dummy payment gateway.
5. After payment, a booking confirmation page is displayed.

--------------------------------------------------
USE CASES
--------------------------------------------------
- Book museum event tickets through a simple conversational chatbot.
- Take a virtual tour of the museum from anywhere.
- Participate in an interactive quiz to engage visitors.
- Provide a quick and user-friendly event booking system.
